# Security

Report a security problem in shulker privately through
[Report a vulnerability](https://github.com/shulker-sh/shulker/security/advisories/new), not in a public issue.

What shulker checks, what it doesn't, and how its own releases are built and verified are on the
[Security](https://shulker.sh/docs/security) page, and `shulker security` lists each protection.

A mod that looks malicious is its provider's to take down: the Security page says how to report one to Modrinth or
CurseForge.
